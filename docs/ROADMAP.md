# Roadmap

| Phase   | Scope                                                                      |
| ------- | -------------------------------------------------------------------------- |
| FASE 0  | Foundation                                                                 |
| FASE 1  | Authentication, Users, Roles, Permissions, User-Branch                     |
| FASE 2  | Catalog, Products, Categories, Laboratories, Barcodes, Price Lists, Prices |
| FASE 3  | Suppliers, Purchases, Partial Receipts, Lots                               |
| FASE 4  | Inventory, Balances, Movements, Expiration, Adjustments                    |
| FASE 5  | Transfers between branches                                                 |
| FASE 6  | Cash registers and cash sessions                                           |
| FASE 7  | Sales, sale items, multiple payments, FEFO                                 |
| FASE 8  | Returns and cancellations                                                  |
| FASE 9  | Reports and audit                                                          |
| FASE 10 | Production hardening, backups, observability, security, performance        |

Post MVP: ARCA, recipes/prescriptions, healthcare and supplier integrations, e-commerce, WhatsApp and advanced analytics.
